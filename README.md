# Fazendinha — versão de teste completa (demo 2)

Versão de teste do app infantil de colorir **Fazendinha** no navegador: a fazenda inteira está aberta, sem compra, e os caminhos entre os lugares já aparecem liberados. Serve para validar o app e conferir os idiomas (português e inglês, na área dos pais).

Acesse: https://sandroldias.github.io/fazendinha-demo2/

Este repositório guarda apenas a versão publicada (gerada por `flutter build web`); o código do app fica em um repositório privado.
